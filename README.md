# BELLE FLAMZ

## Kinetic Sculptures of Light & Scent

**Belle Flamz** is a premium, high-tech digital experience for a luxury candle manufacturing business. It combines artisanal craftsmanship with cutting-edge web design to showcase custom-designed, fragrant, and exotic candles available for retail and wholesale.

---

## 🕯️ Key Features

### 🌪️ Cinematic Hero Experience

- **Asymmetric Branding**: Elegant, left-aligned typography for a modern, editorial feel.
- **Dynamic Background**: Optimized flame glow and floating ember particles for a living atmosphere.
- **Brand Identity**: Highlighting custom design, exotic scents, and artisan manufacturing.

### 🖼️ The Gallery (Immersive Preview)

- **Interactive Grid**: A split-screen layout featuring a deep-zoom preview on the left and a tile-based grid on the right.
- **Intelligent Navigation**: Seamlessly transition between artifacts with a 2-previous, 2-next "tiny frame" navigation system.
- **Scroll Mastery**: Beautifully faded grid with custom scrollbar mechanics.

### 🛠️ Atelier Custom

- **Geometry Forge**: Choose between classic _Pillar_, elegant _Jar_, or a unique _Custom_ design.
- **Bespoke Vision**: Upload your own designs and inspirations directly into the studio.
- **Color Mastery**: Real-time chromatic selection with localized glow effects.

### 🧪 Fragrance Archive

- **Desire-Based Search**: A streamlined interface to find essences that match your frequency.
- **Popularity Ranking**: Scientific sorting by allure, ensuring the most sought-after scents are always at the forefront.

### ⚡ Animation & Physics

- **Section Overlap**: On scroll, sections glide over each other with a curtain-like overlap effect.
- **Dynamic Blur**: Smooth transitioning from 100% to 80% visibility as elements enter the void.
- **Pseudo-Rendering**: Components reveal themselves progressively to create an alive, responsive interface.

## 🛠️ Technology Stack

- **Framework**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion 12](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Build System**: [Vite 6](https://vitejs.dev/)
- **Data**: Centralized JSON architectures for Gallery and Inventories

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- NPM / PNPM

### Installation

1. Clone the repository:
   ```bash
   git clone [repository-url]
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Launch the development server:
   ```bash
   npm run dev
   ```

### Project Structure

- `src/data/`: JSON archives for fragrances and gallery contents.
- `components/sections/`: Modular interactive sections.
- `hooks/`: Custom state and animation logic.
- `public/gallery/`: Image assets for the candle collection.
